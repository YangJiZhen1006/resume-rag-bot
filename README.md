# 📄 AI 简历问答机器人 (Resume RAG Bot)

这是一个基于 **RAG (检索增强生成)** 架构开发的个人 AI 简历助手。它能够读取多版本的个人简历，并通过自然语言对话精准回答关于项目经验、技术栈、教育背景等问题。此外，它还具备**简历与目标岗位 JD 的智能匹配度分析**功能。

## ✨ 核心功能

- 🗣️ **简历问答**：直接向机器人提问，它会严格根据简历片段给出准确回答，不胡编乱造。
- 📂 **多版本支持**：支持导入不同岗位的简历（如开发岗、测试岗），通过侧边栏一键切换，数据互不干扰。
- 🎯 **JD 匹配度分析**：粘贴目标公司的岗位 JD，AI 会自动检索简历，输出包含“综合评分、核心优势、潜在差距与建议”的专业分析报告。
- 💬 **多轮对话与清爽 UI**：基于 Streamlit 构建的宽屏聊天界面，支持清空对话、历史记录保留，交互流畅。

## 🧠 技术架构 (RAG 流程)

1. **数据加载与分块**：使用 `PyPDFLoader` 读取 PDF 简历，通过 `RecursiveCharacterTextSplitter` 进行文本切片（Chunk Size: 600）。
2. **向量化与存储**：使用本地开源模型 `BAAI/bge-small-zh-v1.5` 将文本转化为向量，并持久化存储在 `Chroma` 向量数据库中（通过 Metadata 元数据标签区分不同版本的简历）。
3. **智能检索与过滤**：使用 LangChain 的 Retriever 机制，根据用户当前选择的简历版本进行 Metadata 过滤，确保检索准确率。
4. **大模型生成**：调用智谱开放平台（GLM-4-Flash）大模型，结合检索到的上下文生成最终回答或分析报告。
